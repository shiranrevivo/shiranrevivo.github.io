## ניווט
Home 01 (→ index.html) · Work 02 (→ projects.html) · About 03 (→ about.html) · CV 04 (→ cv.html) · Contact 05 (→ contact.html). כל קישור מוביל לעמוד נפרד, ולא לגלילה לסקשן. הניווט משוכפל בכל העמודים, וכשמוסיפים קישור צריך לעדכן את כולם. סקשני About ו-Contact נשארו גם בדף הבית, ולכן שינוי תוכן צריך לעשות בשני המקומות.
אם התוכן ב-PDF משתנה, צריך לעדכן גם את `cv.html` ידנית.

## data.js
```js
window.CATEGORIES = { ux, ui, dashboard, mobile, web, graphic, set }   // set תמיד אחרון; dashboard = Dashboards (מערכות מורכבות)
window.PROJECTS = [{ id, title, categories: [...], featured }]
// פרויקט עם עמוד: { id, title, subtitle, categories, cover: '…16:10…', images: [{ src, alt, w, h }, …], embed?: { src, ratio, label } | [ {…}, {…} ] }
// embed אופציונלי, רק בפרויקטים שצריכים. אפשר אחד או רשימה, והוא מוצג תמיד אחרי התמונות לפי הסדר. נשמרת רק הכתובת (https). האתר בונה iframe עם sandbox בתוך חלון רטרו, ובמובייל הגובה 72vh  → הכרטיס הופך ל-<a href="project.html?id=…">
// case study: { id, title, subtitle, categories, cover, page: 'case-<id>.html' }  → הכרטיס מקשר ישר לעמוד (pageHref), ו-project.html?id= מפנה אליו
// set design: { id, title, categories: ['set'], cover: 'assets/img/set/x.jpg', video: 'assets/video/x.mp4' | YouTube | Vimeo }
```

- **הוספת פרויקט** = הוספת אובייקט למערך. הבית והסינון מתעדכנים לבד
- כרגע 10 פרויקטים placeholder (`project-01` עד `project-10`; 09–10 נוספו כדי לבדוק את הדפדוף) ו-8 סטים (7 ב-YouTube, 1 בנגן Adobe של Behance): `set-01` (I love you), `set-02` (Paradise Express), `set-03` (Death In Umm Al-Hiran), `set-04` (Click-to-Call, עם cover משלו `assets/img/set/click-to-call.jpg`, פריים 0.05s מהקובץ, בלי כתוביות), `set-05` (Love Letter to My Brother, cover `love-letter.jpg` מה-og:image באתר myportfolio שלה, בלי הפסים השחורים, 2000×1250), `set-06` (30 and Trying, cover `30-and-trying.jpg` מה-og:image, חיתוך ממורכז), `set-07` (Floortime, cover `floortime.jpg` מ-nfct.org.il, 1298×811), `set-08` (Hide and Seek, נגן Adobe CCV מ-Behance, cover `hide-and-seek.jpg` מפריים 35.5s של גרסת ה-1080p)

## לוגיקת ה-Loader
מוצג רק בכניסה ראשונה וברענון, לא במעבר בין עמודים:
- סקריפט inline ב-`<head>` של index.html בודק `performance.getEntriesByType('navigation')[0].type` ואת הדגל `sessionStorage['px-internal']`
- קליק על לינק פנימי (אותו origin, pathname שונה) מציב את הדגל
- `back_forward` או ניווט פנימי שאינו reload: מוסיף `.skip-loader` ל-`<html>`
