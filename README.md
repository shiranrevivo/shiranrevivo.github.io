# Shiran Revivo — Portfolio

Static retro-pixel portfolio (HTML/CSS/JS, no build step). Open `index.html` or serve the folder with any static server.

## Structure
- `index.html`, `projects.html`, `project.html`, `about.html`, `cv.html`, `contact.html`, `404.html`, `case-*.html` — pages
- `assets/` — css, js, fonts, images
- `design-system/` — brand book + design system (the "bible"), tokens, exported assets, tools. Not loaded by the site
- `context/` — project brief, architecture, decisions, TODO, brand-book summary
- `CLAUDE.md` — project instructions for Claude Code
